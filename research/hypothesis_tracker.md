# Hypothesis tracker

This document answers one question: for every hypothesis and every registered test of the project, what was claimed, where and when was it registered, on which data was it tested, what was the outcome with its number, how strong is that evidence, and in which file can it be checked? Nulls and reversals are listed with the same weight as supported results. Numbers are read from the result files named in the last column. The final claims are those of [`paper/report.md`](../paper/report.md).

## How to read the table

**Evidence tiers.** Each row carries exactly one. Rows of different tiers are never pooled.

| Tier | Meaning |
|---|---|
| Registered held-out | Test fixed before any model response on the test split; run once on 63 test families. |
| Registered development | Test or decision rule fixed before any response on its dev items. |
| Prospective test of an amended method | EOP on the held-out split. The method was amended after dev data had been seen; the protocol for the test split was frozen before any test response. |
| Rewording study | Registered separately, on 18 dev families; never used to change EOP. |
| Follow-up, registered after the held-out results were viewed | Studies 1–3, on train-split families no model had seen; each frozen before its first response and analysed once. Their questions were chosen with knowledge of the earlier results. |
| Exploratory | Descriptive. No registered test applies on that split. This includes analyses registered as descriptive and conditions added after seeing dev data. |
| No-model baseline | Exact oracle; rule-based parser followed by the exact planner. |

**Conventions.** Model order in lists: qwen3.5-397b / qwen3.8-27b / deepseek-v4-flash / gemma-4-26b +schema. A list of three leaves out the model named in the row. Modes: E2E (End-to-End), DC (Detection-Controlled). Rates count a failed or unreadable answer as wrong. Intervals are 95% family-clustered bootstrap intervals. Holm p-values are adjusted within the family of tests named in the registration; "< 0.001" stands for a stored value of 0.0, which means no bootstrap resample fell at or below the threshold. Development split: 72 families, 401 resolvable states. Held-out split: 63 families, 342 resolvable states, 402 counterfactual pairs.

**Result files.** DEV = [`results/aggregate/v3dev/pilot_dev/summary.json`](../results/aggregate/v3dev/pilot_dev/summary.json); TEST = [`results/aggregate/final_test/v3/pilot_test/report.md`](../results/aggregate/final_test/v3/pilot_test/report.md) with [`summary.json`](../results/aggregate/final_test/v3/pilot_test/summary.json); TABLES = [`results/aggregate/final_test/RESULTS_TABLES.md`](../results/aggregate/final_test/RESULTS_TABLES.md); INDEX = [`docs/EXPERIMENT_INDEX.md`](../docs/EXPERIMENT_INDEX.md), whose §3 quotes the dev values with their keys.

## Notes

- **Reversals.** The registered direction of H2 and H3 is positive. On the held-out split, two models show a significant difference in the opposite direction for each. For H3, [`paper/report.md`](../paper/report.md) §4.1 states the result for qwen3.8-27b; the opposite-direction results for qwen3.5-397b and gemma are read here from `summary.json` and from the "E5" table of TEST.
- **Family-wise control.** Holm correction is applied within each family of tests. No correction is applied across F0, F1 and F2; [`PREREG_FINAL.md`](../PREREG_FINAL.md) §5 states this in advance.
- **Denominators.** In TEST, an item of gemma +schema with no response is left out of the denominator (341 instead of 342). The EOP analysis counts it as wrong. The registered rule is "all attempted".
- **First view.** The held-out results were first analysed on 2026-11-15 at 20:23 UTC, during a provider outage and before one model's run had finished, under a rule committed beforehand ([`INTERIM_NOTE.md`](../results/aggregate/final_test/INTERIM_NOTE.md)). Every held-out number in the table is from the second analysis, on the complete data.
- **Study 3 supplement.** The interval of the rise in accepted-but-wrong extractions is named in the registration and was not printed by the frozen analysis. It was computed afterwards by `experiments/repair_supplement.py` from the same records (commit `1b6af3b`).
- **Not registered as tests and not run:** risk sensitivity (E11), structural shift (E12), external validity (E13), the computation-capability control (E14), relevance against necessity (T3). See the [original roadmap](original_roadmap.md) and the [experiment registry](../experiments/experiment_registry.md).
