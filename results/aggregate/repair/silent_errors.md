# Silent semantic errors in Study 3 (exploratory, post hoc)

**Status.** Exploratory and post hoc: designed 2026-11-15, after the Study 3 results had been seen; not registered. No model calls: the stored Study 3 records are re-read through the functions of `experiments/run_repair.py`. Generated by `experiments/analyze_silent_errors.py`.

**Method.** For each extraction the reader accepted but whose state differs from the true state (accepted but wrong), the exact planner plans on the extracted state and the plan is scored on the true item (oracle labels). Classes: still optimal; sufficient but costlier; insufficient; unnecessary intervention (true state already sufficient, plan acts); wrong stop or defer; planner error (the planner rejected the state, so the error is not silent). A *silent consequential error* is accepted, has a wrong state, is not rejected by the planner, and its plan is not optimal on the true state. Per-item rates use all 174 items of an arm; intervals are 95% family-clustered bootstrap (12 families).

Distinguish: exact-state accuracy (state equals the true state), parser acceptance (the reader accepts the answer), plan optimality and sufficiency (scored on the true state), and undetected semantic errors (accepted, wrong state).
